# 微信公众号文章生成 Skill

根据用户提供的主题，生成适合微信公众号发布的高质量文章，并保存为 Markdown 文件。

## 使用方式

用户可以这样触发：
- `/wechat-article-generator 主题：[主题]`
- `/wechat-article-generator 主题：[主题] 风格：[知识科普|故事叙述|干货列表]`
- `/wechat-article-generator 主题：[主题] 风格：[风格] 受众：[目标受众] 字数：[目标字数]`

## 工作流程

按以下步骤完成任务，使用 TodoWrite 追踪进度。

### 第一步：收集信息

如果用户没有提供以下信息，**主动询问**：
1. **主题**（必填）：文章核心话题
2. **风格**（可选，默认：干货列表）：
   - `知识科普`：深度解析，带数据和案例支撑，适合教育类内容
   - `故事叙述`：以故事或案例开头，引人入胜，适合情感和品牌内容
   - `干货列表`：「X个方法」「X个技巧」等列表形式，适合实用内容
3. **目标受众**（可选，默认：大众读者）：例如职场人、学生、创业者、宝妈等
4. **目标字数**（可选，默认：1500字）：建议范围 800-3000 字

### 第二步：规划文章结构

根据风格选择对应结构模板：

#### 知识科普结构
```
标题：[引发好奇/打破认知的标题]
摘要（50字以内）

一、[现象/问题引入]
二、[核心知识点1] + 数据/案例
三、[核心知识点2] + 数据/案例  
四、[核心知识点3] + 数据/案例
五、[总结与启示]
结语 + 互动引导
```

#### 故事叙述结构
```
标题：[情感共鸣型标题]
摘要（50字以内）

开篇故事/场景（制造代入感）
↓
转折：引出核心问题
↓
解决历程（带细节和对话）
↓
感悟升华
结语 + 互动引导
```

#### 干货列表结构
```
标题：[X个XXX，让你XXX]
摘要（50字以内）

引言（痛点共鸣，3-5句）
① [要点1] + 说明 + 实操建议
② [要点2] + 说明 + 实操建议
③ [要点3] + 说明 + 实操建议
...
总结一句话
结语 + 互动引导
```

### 第三步：撰写文章

写作要求：

**标题要求：**
- 长度 15-25 字，包含核心关键词
- 制造悬念或情感冲击，避免平铺直叙
- 可参考格式：「为什么XXX？」「XXX的人，最终都XXX」「X个XXX，帮你XXX」

**正文要求：**
- 开篇 100 字内必须抓住读者，可用故事、数据、反常识的结论开头
- 每段不超过 150 字，公众号读者在手机上阅读，段落要短
- 每 300-400 字插入一个小标题（加粗）
- 核心观点用 **加粗** 标注
- 适当使用 emoji 增加可读性（不要滥用，每屏约 1-2 个）
- 数据和案例要具体，避免空洞表述
- 结尾必须有互动引导，例如「你有什么想法？欢迎在留言区分享」

**排版要求：**
- 正文用普通段落，不用 Markdown 列表语法（微信不渲染）
- 小标题用 `**小标题**` 格式
- 重点句子独立成段
- 文末附「关注我们」或「分享给朋友」引导语

### 第四步：保存文件

将文章保存为 Markdown 文件：

1. 文件路径：`./articles/YYYY-MM-DD-[主题slug].md`
2. 如果 `articles/` 目录不存在，先创建它
3. 文件名中的主题 slug：中文主题转为拼音缩写或英文关键词，用连字符分隔

文件格式：
```markdown
---
title: [文章标题]
date: YYYY-MM-DD
style: [知识科普|故事叙述|干货列表]
topic: [主题]
audience: [目标受众]
word_count: [实际字数]
---

[文章正文]
```

### 第五步：输出摘要

完成后告知用户：
- 文件保存路径
- 文章字数
- 建议的发布时间（工作日早7-9点、中12-13点、晚20-22点为公众号发文黄金时段）
- 可选的后续优化方向（SEO标题优化、配图建议等）

## 注意事项

- 内容必须原创，不抄袭，不生成违规内容
- 避免夸大宣传、虚假数据
- 政治敏感话题婉拒或谨慎处理
- 如果用户提供的主题信息不足以写出高质量文章，主动追问细节
