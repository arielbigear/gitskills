# 微信公众号文章生成 Skill

根据选题库中的选题和人设素材库中的素材，生成适合微信公众号发布的高质量文章，并保存为 Markdown 文件。

## 素材库路径

- **选题库**：`~/Documents/obsidian-人设素材库/选题库/`（每个选题一个 .md 文件）
- **人设素材库**：`~/Documents/obsidian-人设素材库/人设素材库/`（每个人设一个 .md 文件）
- **文章输出目录**：`~/Documents/obsidian-人设素材库/articles/`

## 使用方式

用户可以这样触发：
- `/wechat-article-generator` — 列出可用选题，让用户选择
- `/wechat-article-generator 选题：[选题文件名]` — 直接指定选题
- `/wechat-article-generator 选题：[选题文件名] 人设：[人设文件名] 风格：[风格]`

## 工作流程

按以下步骤完成任务，使用 TodoWrite 追踪进度。

### 第一步：读取选题库

1. 列出 `~/Documents/obsidian-人设素材库/选题库/` 下所有 .md 文件
2. 如果用户没有指定选题，展示选题列表供用户选择：
   ```
   📋 可用选题：
   1. [文件名1]
   2. [文件名2]
   ...
   请输入选题编号或名称：
   ```
3. 用户选定后，**完整读取该选题文件**，提取：
   - 选题标题 / 核心话题
   - 写作角度或切入点（如有）
   - 目标受众（如有）
   - 关键词（如有）
   - 任何补充说明

### 第二步：读取人设素材库

1. 列出 `~/Documents/obsidian-人设素材库/人设素材库/` 下所有 .md 文件
2. 如果用户没有指定人设，展示人设列表供用户选择：
   ```
   🎭 可用人设：
   1. [人设文件名1]
   2. [人设文件名2]
   ...
   请输入人设编号或名称（或直接回车使用默认风格）：
   ```
3. 用户选定后，**完整读取该人设文件**，提取：
   - 写作口吻（正式/轻松/犀利/温暖等）
   - 常用句式和表达习惯
   - 文章定位和受众特征
   - 核心价值观或主张
   - 禁忌和注意事项
   - 典型素材（金句、案例、数据等）

### 第三步：确认风格

如果用户没有指定风格，根据选题内容和人设特征推荐最合适的风格，告知用户并确认：

- `知识科普`：深度解析，带数据和案例支撑，适合教育类内容
- `故事叙述`：以故事或案例开头，引人入胜，适合情感和品牌内容
- `干货列表`：「X个方法」「X个技巧」等列表形式，适合实用内容

### 第四步：规划文章结构

综合选题信息、人设素材、选定风格，制定文章结构：

#### 知识科普结构
```
标题：[引发好奇/打破认知的标题]
摘要（50字以内）

一、[现象/问题引入] ← 结合人设切入点
二、[核心知识点1] + 来自人设素材库的数据/案例
三、[核心知识点2] + 来自人设素材库的数据/案例
四、[核心知识点3] + 来自人设素材库的数据/案例
五、[总结与启示]
结语 + 互动引导（符合人设口吻）
```

#### 故事叙述结构
```
标题：[情感共鸣型标题]
摘要（50字以内）

开篇故事/场景 ← 优先使用人设素材库中的真实案例
↓
转折：引出核心问题
↓
解决历程（带细节和对话，语气符合人设）
↓
感悟升华 ← 体现人设核心价值观
结语 + 互动引导
```

#### 干货列表结构
```
标题：[X个XXX，让你XXX]
摘要（50字以内）

引言（痛点共鸣，3-5句，符合人设口吻）
① [要点1] + 说明 + 来自素材库的实操建议
② [要点2] + 说明 + 来自素材库的实操建议
③ [要点3] + 说明 + 来自素材库的实操建议
...
总结一句话（人设金句风格）
结语 + 互动引导
```

### 第五步：撰写文章

**必须严格遵守人设素材中的写作规范**，同时符合以下公众号通用要求：

**标题要求：**
- 长度 15-25 字，包含核心关键词
- 制造悬念或情感冲击，避免平铺直叙
- 风格符合人设定位

**正文要求：**
- 开篇 100 字内必须抓住读者，优先使用人设素材库中的故事或数据开头
- 每段不超过 150 字（手机阅读友好）
- 每 300-400 字插入一个小标题（**加粗**）
- 核心观点用 **加粗** 标注
- 适当使用 emoji（每屏约 1-2 个，风格与人设匹配）
- 素材库中的金句、案例、数据**优先使用**，自然融入正文
- 结尾必须有互动引导，语气符合人设

**排版要求：**
- 正文用普通段落，不用 Markdown 列表语法（微信不渲染）
- 小标题用 `**小标题**` 格式
- 重点句子独立成段

### 第六步：保存文件

将文章保存为 Markdown 文件：

1. 文件路径：`~/Documents/obsidian-人设素材库/articles/YYYY-MM-DD-[选题slug].md`
2. 如果 `articles/` 目录不存在，先创建它
3. 文件名 slug：取选题文件名的核心词，用连字符分隔

文件格式：
```markdown
---
title: [文章标题]
date: YYYY-MM-DD
style: [知识科普|故事叙述|干货列表]
topic_source: [选题文件名]
persona_source: [人设文件名]
word_count: [实际字数]
---

[文章正文]
```

### 第七步：输出摘要

完成后告知用户：
- 文件保存路径
- 文章字数
- 使用了哪个选题 + 哪个人设
- 素材库中哪些素材被引用了（方便用户核查）
- 建议的发布时间（工作日早7-9点、中12-13点、晚20-22点为黄金时段）

## 注意事项

- 人设素材库的内容优先级高于通用写作规范，若有冲突以人设为准
- 选题文件中已有的方向和角度要忠实执行，不要自行改变立意
- 使用素材库中的案例/数据时，按原文引用，不要篡改
- 内容必须原创，不抄袭，不生成违规内容
- 政治敏感话题婉拒或谨慎处理
